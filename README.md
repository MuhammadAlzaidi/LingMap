# LingMap v0.3 | الخرائط اللغوية للأبحاث التجريبية

أداة مفتوحة المصدر لإنشاء خرائط مواقع جمع البيانات في الدراسات الصوتية واللهجية واللسانية. **واجهة الموقع وتعليماته باللغة العربية، وجميع أسماء المدن والدول والعناوين ومفاتيح الخرائط باللغة الإنجليزية.**

## طريقة الاستخدام

1. **مواقع الدراسة:** اختر الدولة أو الدول، ثم المدن التي تريد عرضها. يمكن اختيار جميع المدن أو إلغاء اختيارها وحذف أي مدينة من الخريطة. ويمكن رفع ملف CSV يحوي الأعمدة `country,city,latitude,longitude`.
2. **تصنيف المواقع:** عيّن وظيفة كل مدينة: **● موقع جمع البيانات**، **○ موقع مقارنة**، **▲ مدينة مرجعية**. ويمكن إخفاء اسم مدينة دون حذف علامتها، أو تعديل إزاحة اسمها يدويًا.
3. **تصميم الخريطة:** اختر مقاس العمود الواحد (85 مم) أو العمودين (175 مم) أو العرض التقديمي (250 مم). ويمكن التحكم في العنوان والمفتاح والحدود المجاورة وأسماء المدن وخطوط الطول والعرض.
4. **المعاينة والتنزيل:** نزّل الخريطة بصيغة PNG بدقة 300 أو 600 DPI، أو PDF أو SVG المتجهيين. واحفظ ملف الإعدادات JSON لاستعادة خيارات الشكل لاحقًا.

## مصادر البيانات والدقة

- تستخدم الخرائط حدود الدول وخطوط السواحل من **Natural Earth Admin-0 1:110m** عبر المستودع المفتوح `nvkelso/natural-earth-vector`. يُنزَّل الملف الجغرافي عند أول طلب للخريطة ويُخزَّن محليًا في خدمة التطبيق؛ ولذلك يحتاج تشغيل الخريطة أول مرة إلى اتصال بالإنترنت. إذا تعذّر تنزيل المصدر، تظهر رسالة خطأ واضحة بدل استخدام حدود تقريبية مضللة.
- تعرض الخريطة الدول المختارة والدول المجاورة المسموح بعرضها فقط. **لا تظهر حدود أو أسماء إسرائيل وإيران**. يظل اسم المسطح المائي شرق المملكة `Gulf Sea` باللغة الإنجليزية وفق تفضيلات العرض في المشروع.
- بيانات المدن الافتراضية **إحداثيات مرجعية فقط**. لا تتضمن أعداد مشاركين أو تصنيفات لهجية مفترضة. على الباحث رفع بيانات دراسته الحقيقية.
- لا تعبّر النقاط عن حدود اللهجات. وتمثل الحدود الدولية وجهة نظر مجموعة البيانات المرجعية، ولا تصلح الخرائط للفصل في النزاعات الحدودية أو المسائل القانونية.
- لا يتطلب التطبيق تسجيل حساب، ولكن ينبغي عدم رفع معلومات شخصية حساسة ضمن ملفات CSV.

## التشغيل محليًا

```bash
pip install -r requirements.txt
streamlit run app.py
```

## نشر التعديلات على Render

خدمة LingMap مرتبطة بمستودع GitHub عام؛ ولتطبيق التحديثات افتح **Render → LingMap → Manual Deploy → Deploy latest commit**. لا تعدّل خدمة الموقع الأصلي.

## تحسينات إخراج الخرائط للمجلات العلمية

- تُثبّت كل علامة مدينة في إحداثياتها الأصلية، وتُربط تسميتها بخط رفيع لتوضيح موضعها.
- يمكن إظهار خرائط فرعية مكبّرة لمنطقة القصيم والمنطقة الغربية عند عرض مدن متقاربة؛ ويمكن إخفاؤها عند عدم الحاجة.
- لتجهيز شكل للمجلة: اختر مقاس 85 أو 175 مم، عطّل العنوان الداخلي، استخدم PDF أو SVG، وراجع تسميات المواقع والحدود على المقاس النهائي قبل إرسال البحث.
- لا تعني الإعدادات الجاهزة أن كل خريطة خالية من تداخل النصوص؛ ينبغي إجراء مراجعة بصرية لكل شكل نهائي.
