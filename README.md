# LingMap | خريطة الدراسات اللغوية العربية

تطبيق لإنشاء خرائط لمواقع الدراسات اللغوية واللهجية وإخراجها بجودة مناسبة للنشر العلمي.

## لغة الواجهة والخرائط

**واجهة الموقع وتعليمات الاستخدام باللغة العربية، أما جميع النصوص الظاهرة على الخرائط المُنشأة فباللغة الإنجليزية.** يشمل ذلك أسماء الدول والمدن وعناوين الخرائط والمفاتيح والتسميات الجغرافية. ولا تتغير البيانات الجغرافية أو الإحداثيات أو أنماط الرسم بسبب لغة الواجهة. وتظهر التسمية `Gulf Sea` باللغة الإنجليزية بحسب إعدادات المشروع.

## طريقة الاستخدام

1. افتح التطبيق في متصفح الإنترنت بعد نشره.
2. اختر الدولة والمدن أو مواقع الدراسة المطلوبة باستخدام عناصر التحكم العربية.
3. حدّد إعدادات الخريطة، مثل إظهار أسماء المدن وحجم العلامات والعنوان.
4. عاين الخريطة؛ ستظهر **التسميات المطبوعة على الخريطة باللغة الإنجليزية**.
5. نزّل الخريطة بصيغة PNG أو PDF أو SVG.
6. يمكن أيضًا رفع ملف CSV يتضمن الأعمدة `country,city,latitude,longitude` لإضافة مواقع بحثية.

## الدول المشمولة

المملكة العربية السعودية، والأردن، والعراق، ومصر، والمغرب، وتونس، والجزائر. وتُتاح مدن المملكة ضمن مناطقها الخمس: الوسطى والغربية والشرقية والجنوبية والشمالية.

## تشغيل التطبيق محليًا

بعد إضافة ملفات التطبيق إلى المستودع:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## نشر التطبيق

اربط المستودع بخدمة [Streamlit Community Cloud](https://share.streamlit.io/) واختر `app.py` بوصفه الملف الرئيسي.

**حالة المشروع:** يتضمن هذا المستودع حاليًا ملف التعليمات؛ ولم تُرفع ملفات التطبيق إليه بعد، ولذلك لا يمكن تشغيله من المستودع حاليًا. لا تعني مواقع المدن حدودًا فاصلة بين اللهجات.
