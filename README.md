# LingMap | خرائط مواقع الدراسات اللغوية

تطبيق مجاني ومفتوح المصدر لإنشاء خرائط لمواقع الدراسات اللغوية واللهجية، مع إمكانية تنزيلها بصيغ PNG وPDF وSVG.

## لغة الموقع والخرائط

**تعليمات الاستخدام وأزرار الموقع باللغة العربية. أما جميع الأسماء والعناوين والمفاتيح والتسميات الظاهرة على الخريطة المُصدّرة فباللغة الإنجليزية.** مثل: Riyadh وMakkah وMadinah وGulf Sea.

## إعدادات الخرائط العلمية بالأبيض والأسود

تُنشأ الخرائط افتراضيًا بالأسود والأبيض والرمادي لتناسب الطباعة في المجلات العلمية. يمكنك إزالة أي مدينة من قائمة المدن المختارة، ثم تحديد مدينة واحدة أو أكثر بوصفها مواقع جمع البيانات لتظهر بدوائر سوداء ممتلئة، بينما تظهر المدن المرجعية بدوائر بيضاء ذات حدود سوداء. ويمكن إظهار أسماء الدول المجاورة وخطوط الطول والعرض والمفتاح أو إخفاؤها. يتولى التطبيق توزيع أسماء المدن آليًا لتقليل تداخلها.

**ملاحظة:** حدود الدول المضمنة مبسطة، وتظهر الدول المجاورة كتسميات سياقية تقريبية دون حدودها الكاملة؛ لا يُعد هذا الإصدار مصدرًا دقيقًا لخطوط السواحل أو الحدود الدولية.

## طريقة الاستخدام

1. افتح التطبيق في المتصفح.
2. اختر دولة واحدة أو أكثر من القائمة الجانبية.
3. اختر المدن أو مناطق المملكة التي تهمك.
4. أدخل عنوان الخريطة **باللغة الإنجليزية**، ثم اضبط أسماء المدن وحجم العلامات.
5. عاين الخريطة وحمّلها بصيغة PNG أو PDF أو SVG.
6. لإضافة مواقع من دراستك، ارفع ملف CSV يتضمن الأعمدة `country,city,latitude,longitude`. استخدم أسماء الدول باللغة الإنجليزية كما في النموذج المتاح داخل التطبيق.

**تنبيه علمي:** مواقع المدن إيضاحية وليست حدودًا للهجات. وتُعرض حدود الدول المختارة فقط، مع تسمية `Gulf Sea` حسب إعدادات المشروع.

## الدول المدعومة

المملكة العربية السعودية (المناطق الوسطى والغربية والشرقية والجنوبية والشمالية)، والأردن، والعراق، ومصر، والمغرب، وتونس، والجزائر.

## تشغيل التطبيق على الحاسوب

بعد تنزيل المستودع وتثبيت Python:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## نشر الموقع على الإنترنت

1. افتح [Streamlit Community Cloud](https://share.streamlit.io/).
2. سجّل الدخول بحساب GitHub.
3. اختر إنشاء تطبيق جديد من المستودع `MuhammadAlzaidi/LingMap`.
4. اختر الفرع `main` والملف الرئيسي `app.py`.
5. اضغط Deploy وانتظر اكتمال النشر.

**حالة المشروع:** ملفات التطبيق وبيانات المدن وحدود الدول والاختبارات موجودة في هذا المستودع. لم يُنشر التطبيق بعد على Streamlit Community Cloud. تُستخدم حدود مبسطة مأخوذة من بيانات Natural Earth بدقة مناسبة للعرض العام، ولا يُنصح بالاعتماد عليها لتحديد الحدود الدقيقة أو المتنازع عليها.
