# LingMap | خريطة الدراسات اللغوية العربية

**تطبيق مفتوح المصدر لإنشاء خرائط مواقع الدراسات اللهجية والبحوث اللغوية، مع تصدير PNG وPDF وSVG.**

يدعم التطبيق المملكة العربية السعودية (المناطق الوسطى والغربية والشرقية والجنوبية والشمالية)، والأردن، والعراق، ومصر، والمغرب، وتونس، والجزائر.

## طريقة الاستخدام

1. افتح التطبيق في المتصفح بعد نشره على Streamlit Community Cloud.
2. اختر الدولة والمدن التي أجريت فيها الدراسة.
3. حدّد عنوان الخريطة، وطريقة إظهار أسماء المدن، وحجم العلامات.
4. عاين الخريطة ثم نزّلها بصيغة PNG أو PDF أو SVG.
5. يمكنك رفع ملف CSV بأعمدة `country,city,latitude,longitude` لإضافة مواقع الدراسة.

## تشغيل التطبيق محليًا

بعد إضافة ملفات المشروع إلى هذا المستودع:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## النشر

اربط هذا المستودع بـ [Streamlit Community Cloud](https://share.streamlit.io/) وحدد الملف الرئيسي `app.py`.

**ملاحظة:** هذا المستودع يحتوي حاليًا على التعليمات؛ ستُضاف ملفات التطبيق والبيانات قبل تشغيله على الإنترنت. لا تدل مواقع المدن وحدها على حدود اللهجات. تظهر الخرائط فقط الدول المختارة، مع تسمية المسطح المائي شرق السعودية «بحر الخليج» حسب إعدادات العرض الخاصة بالمشروع.
