

## تطبيق الخرائط اللغوية

**أداة بحثية مفتوحة المصدر لإعداد خرائط مواقع الدراسات اللغوية والصوتية واللهجية، مع خيارات تصدير ملائمة للنشر الأكاديمي.**

[**استخدم LingMap الآن — lingmap.arabicling.com**](https://lingmap.arabicling.com/) · [منصة Ẓ.ai الرئيسية](https://www.arabicling.com/) · [المستودع البرمجي](https://github.com/MuhammadAlzaidi/LingMap)

> **لغة الواجهة:** العربية. **لغة الأشكال العلمية المُصدّرة:** الإنجليزية، بما في ذلك أسماء المدن والدول والمسطحات المائية ومفاتيح الرموز.

## نبذة عن المشروع


 تطبيق ويب تفاعلي يساعد الباحثين في اللسانيات وعلم الأصوات واللهجات على تمثيل مواقع جمع البيانات والمقارنة جغرافيًا، دون الحاجة إلى كتابة شيفرة لرسم كل خريطة. يُنشئ التطبيق خرائط بتدرجات الرمادي، ويتيح التحكم في العلامات والتسميات والمقاسات وملفات التصدير.

**رابط الاستخدام المباشر:** **https://lingmap.arabicling.com/**

لا يحتاج المستخدم إلى تثبيت أي برامج للاستفادة من النسخة المنشورة.

## الوظائف الرئيسية

| الوظيفة | الوصف |
| --- | --- |
| اختيار النطاق الجغرافي | اختيار دولة أو أكثر من الدول المدعومة، وتصفية مدن المملكة بحسب المنطقة. |
| مواقع مخصصة | استيراد مواقع الدراسة من ملف CSV بإحداثيات جغرافية فعلية. |
| تصنيف المواقع | التمييز بين موقع جمع البيانات وموقع المقارنة والمدينة المرجعية برموز مختلفة. |
| ضبط التسميات | إظهار أسماء المدن أو إخفاؤها، وتعديل مواضعها يدويًا أو ترك التطبيق يقترح مواضع تقلل التداخل بين التسميات والعلامات. |
| السياق الجغرافي | عرض الدول المجاورة والسواحل بحسب نطاق الخريطة وإعداداتها، مع تمييز بصري هادئ للمسطحات المائية. |
| خرائط فرعية | إتاحة خرائط مكبّرة لبعض المناطق التي تتقارب فيها المواقع. |
| إعدادات النشر | مقاسات 85 مم و175 مم و250 مم، وخيارات عرض العنوان والمفتاح والمحاور. |
| التصدير | PNG بدقة 300 أو 600 DPI، بالإضافة إلى PDF وSVG، مع إعادة استخدام الملفات المولدة عند التنزيل. |
| قابلية إعادة الإنتاج | حفظ إعدادات الشكل في JSON واستعادتها لاحقًا. |

**الدول المدعومة حاليًا:** المملكة العربية السعودية، والأردن، والعراق، ومصر، والمغرب، وتونس، والجزائر.

## دليل الاستخدام السريع

1. افتح **[lingmap.arabicling.com](https://lingmap.arabicling.com/)**.
2. في **مواقع الدراسة**، حدد الدول والمناطق والمدن المطلوبة، أو ارفع ملف مواقع خاصًا بك.
3. في **تصنيف المواقع**، اختر دور كل موقع واضبط ظهور تسمياته.
4. في **تصميم الخريطة**، اختر مقاس الشكل وإعدادات الحدود والتسميات والمفتاح.
5. بعد الانتهاء من جميع الإعدادات، اضغط **تحديث الخريطة** لإنشاء الشكل مرة واحدة، ثم راجعه بصريًا وصدّره بالتنسيق المناسب.
6. احفظ إعدادات JSON إذا أردت إعادة إنتاج الشكل أو تعديله لاحقًا.

### صيغة ملف المواقع CSV

الحد الأدنى من الأعمدة المطلوبة:

```csv
country,city,latitude,longitude
Saudi Arabia,Riyadh,24.7136,46.6753
Saudi Arabia,Jeddah,21.5433,39.1728
```

- تُكتب أسماء الدول وفق التسميات الإنجليزية التي يتعرف عليها التطبيق.
- تُسجّل الإحداثيات بالدرجات العشرية؛ **latitude** لخط العرض و**longitude** لخط الطول.
- الأمثلة للتوضيح فقط؛ يجب التحقق من إحداثيات مواقع الدراسة الفعلية قبل النشر.
- لا ترفع بيانات شخصية أو معلومات حساسة عن المشاركين.

## أسلوب إنشاء الخريطة

يتيح التطبيق ضبط الخيارات في نموذج واحد دون إعادة توليد الخريطة عند تغيير كل إعداد. بعد الانتهاء، اضغط **تحديث الخريطة** لتوليد المعاينة وملفات التصدير. تُحفظ الملفات المولدة مؤقتًا في جلسة المستخدم، ويمكن تنزيلها دون إعادة حساب الخريطة. تساعد خوارزمية وضع التسميات على تقليل التداخل، لكنها لا تغني عن مراجعة الباحث للشكل النهائي، ولا سيما في المواقع المتقاربة.

## التصدير للأبحاث والمجلات العلمية

لإعداد شكل مناسب لمقال علمي، يُنصح باختيار عرض **85 مم** (عمود واحد) أو **175 مم** (عمودان)، وإخفاء العنوان الداخلي إذا كانت المجلة تتطلب عنوان الشكل في متن المقال. يفضّل استخدام **PDF أو SVG** عند الحاجة إلى رسومات متجهية قابلة للتكبير، أو **PNG بدقة 600 DPI** عند اشتراط صورة نقطية عالية الدقة.

**مراجعة الباحث ضرورية:** افحص تداخل التسميات، ومواضع العلامات، ومفتاح الرموز، وحدود الخريطة على الحجم النهائي. إعدادات التصدير لا تضمن تلقائيًا مطابقة متطلبات جميع المجلات.

## البيانات الجغرافية والاعتبارات العلمية

يعتمد التطبيق على بيانات **[Natural Earth](https://www.naturalearthdata.com/)** بدقة **1:110m**، من خلال ملفات GeoJSON المتاحة في [مستودع Natural Earth Vector](https://github.com/nvkelso/natural-earth-vector). تُحمّل البيانات عند الحاجة وتُخزّن محليًا على خدمة التطبيق. قد يحتاج إنشاء أول خريطة إلى اتصال بالمصدر الجغرافي.

تُعرض السواحل والمسطحات المائية وفق نطاق الخريطة والبيانات الجغرافية المستخدمة، مع الحفاظ على تصميم أكاديمي محايد بتدرجات الرمادي. وتُستخدم التسميات الجغرافية المعتمدة في إعدادات التطبيق لأغراض العرض الخرائطي فقط. ولا تُستخدم الحدود المعروضة لإثبات حدود اللهجات أو لتقديم أحكام بشأن الحدود السياسية؛ فهي تمثيل خرائطي مستند إلى المصدر الجغرافي.

بيانات المدن الافتراضية نقاط مرجعية وليست بيانات مشاركين أو نتائج بحثية. ينبغي للباحث توفير بياناته والتحقق منها وتوثيق منهجيته بصورة مستقلة.

## تشغيل المشروع محليًا

يتطلب المشروع بيئة Python مناسبة، ثم:

```bash
git clone https://github.com/MuhammadAlzaidi/LingMap.git
cd LingMap
python -m pip install -r requirements.txt
streamlit run app.py
```

يعمل التطبيق باستخدام **Streamlit**، مع **Pandas** لمعالجة البيانات، و**GeoPandas** للبيانات الجغرافية، و**Matplotlib** لرسم الخرائط.
